# Data Processing Addendum (DPA) Summary (Draft)

Effective date: 2026-04-16

This DPA summary is a starter template for customer and legal review.

## 1. Roles

- Customer: Data Controller (or Business, depending on jurisdiction)
- DocSync: Data Processor (or Service Provider)

## 2. Processing Details

- Subject matter: document collaboration and security operations
- Duration: term of service agreement and limited post-termination retention window
- Nature: collection, storage, retrieval, modification, deletion
- Data categories: account identity, content metadata, operational logs

## 3. Processor Obligations

- Process data only on documented instructions
- Apply appropriate technical and organizational security controls
- Assist with data subject rights requests
- Support audit and security inquiries under reasonable terms

## 4. Subprocessors

Subprocessor use requires contractual flow-down and security review.

## 5. Security Measures

Reference controls documented in trust center and security runbooks.

## 6. Breach Notification

Security incidents follow ../runbooks/incident-response.md with customer notification workflow and timelines defined in contract.

## 7. Data Return and Deletion

Return/deletion behavior follows ../security/data-retention-and-deletion.md and applicable contract requirements.

## 8. Transfer Mechanisms

International transfer safeguards must be documented before production deployment.

## 9. Sign-off Requirement

This document is a policy baseline only and must be reviewed and approved by legal counsel before external publication.
